# 🤖 kbot

Telegram bot written in Go.

**Bot:** https://t.me/goncharenkooleksii_bot

---

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/ogoncharenko32/kbot.git
cd kbot
```

Set up your Telegram Bot Token:

```bash
read -s TELE_TOKEN
# Paste your token (Ctrl+Shift+V or Ctrl+V depending on your terminal)
export TELE_TOKEN
```

---

## ▶️ Usage

Start the bot:

```bash
./kbot start
```

---

## 💬 Available Commands

| Command | Description |
|---------|-------------|
| `/start hello` | Returns a welcome message and the current bot version. |
| `/start time` | Returns a current time. |
| `/start date` | Returns a current date. |
